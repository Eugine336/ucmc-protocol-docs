# Contributing to UCMC Protocol Docs

Thanks for helping improve the public UCMC protocol documentation.

## What Contributions Are Accepted

This repository accepts **documentation-only** contributions:

- Typos and grammar fixes
- Clarifications for ambiguous protocol behavior
- Structure and readability improvements
- Diagram improvements
- Glossary consistency updates

Implementation code changes are out of scope for this repository.

## Filing Issues

Please open an issue when you find:

- Incorrect or unclear protocol descriptions
- Missing definitions or inconsistent terminology
- Diagram errors
- Broken links or formatting problems

When possible, include:

- The file and section title
- A short description of the problem
- A suggested correction

## Submitting Pull Requests

1. Open a PR against `main`.
2. Keep the scope focused and documentation-only.
3. Explain why the change improves correctness or clarity.
4. Add or update glossary entries when introducing new protocol terms.

## Documentation Style Guide

- Use clear Markdown headings and short sections.
- Prefer plain language over internal jargon.
- Use Mermaid for architecture and flow diagrams.
- Keep protocol constants and domain strings exact.
- Use the glossary for term consistency across files.

## Source of Truth Note

This public documentation is curated from an internal codebase that is not part of this repository. Contributions should improve public documentation quality without introducing internal operational details.
